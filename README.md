# Real-Time Hand Gesture VFX System

An interactive computer vision application that generates dynamic neon glows, fingertip beams, and magic shield visual effects over real-time webcam video using OpenCV and MediaPipe.

## Features

- **Neon Hand Skeleton**: Multi-layered glow rendering across detected hand joints.
- **Palm Aura**: Soft pulsing radial energy aura centered on the palm.
- **Two-Hand Fingertip Beams**: Connection arcs and contact burst stars when fingertips touch.
- **Doctor Strange-style Magic Shield**: Rotational sacred geometry activated by an open palm.
- **Cinematic Processing**: Real-time atmospheric color tinting and bloom effects.

## Controls

| Key | Action |
| :--- | :--- |
| `a` | Toggle Palm Aura ON/OFF |
| `b` | Toggle Fingertip Connection Beams ON/OFF |
| `s` | Toggle Magic Shield ON/OFF |
| `q` | Quit Application |
